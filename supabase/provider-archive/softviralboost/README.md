# Archived number provider integration

The former Soft Viral Boost implementation is retained here for historical review only. On 2026-10-29, its live catalogue, buy, check, and cancel handlers were replaced with disabled HTTP 410 tombstones and Sparkle's frontend was moved to generic number-service endpoints.

These files are not in the active Edge Functions directory and are not deployed by the workflow. They contain no API key value. Do not restore this implementation without reviewing current pricing, authentication, duplicate-order protection, and refund handling.
